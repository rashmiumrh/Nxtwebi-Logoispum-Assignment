# NxtWebi – Travel Landing Page

A static travel landing page built from a Figma design using **React**, **Vite** and **Tailwind CSS**.

## Screen Resolutions

This website is designed for **3 desktop resolutions**:

| Resolution | Width   |
| ---------- | ------- |
| Large      | 1920px  |
| Medium     | 1440px  |
| Small      | 1280px  |

It is also **fully mobile responsive**, so the layout adapts to tablet and mobile screen sizes.

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- Lato font (bundled locally)

## Project Structure

```
src/
├── assets/       # Images, icons and fonts
├── components/   # Page sections (header, hero, packages, footer, ...)
├── data/         # Static content used by the sections
├── hooks/        # Custom React hooks
├── App.jsx
├── index.css
└── main.jsx
```

## Getting Started

```bash
npm install      # install dependencies
npm run dev      # start the dev server
```
